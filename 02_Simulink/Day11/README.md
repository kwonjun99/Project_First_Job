# Day11 - Switch를 이용한 조건 분기

## 학습 목표

* Switch 블록의 구조 이해
* 조건에 따라 서로 다른 출력 선택
* 자동차 ECU의 조건 분기 로직 이해

---

## 프로젝트 개요

차량 제어기는 하나의 동작만 수행하지 않는다. 운전자의 입력이나 차량 상태에 따라 서로 다른 제어를 수행한다. 이번 실습에서는 Switch 블록을 사용하여 조건에 따라 다른 값을 출력하는 모델을 구현하였다.

---

## 사용한 블록

* Constant
* Switch
* Display

---

## 모델 구성

상단 입력

↓

Switch

↓

Display

하단 입력

Control 입력

---

## 실제 자동차 제어에서 활용

* 브레이크 페달 입력 여부
* 크루즈 컨트롤 ON/OFF
* 자동/수동 모드 전환
* 비상 제동 활성화

모두 조건 분기(Switch) 구조를 기반으로 동작한다.

---

## 학습 내용

* 조건 분기
* Threshold 설정
* Control Signal
* Switch Block

---

## 느낀 점

자동차 ECU는 단순 계산이 아니라 다양한 조건을 실시간으로 판단하여 서로 다른 제어를 수행한다는 점을 이해하였다.
