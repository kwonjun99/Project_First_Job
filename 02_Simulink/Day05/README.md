# Day05 - Mux를 이용한 다중 신호 처리

## 학습 목표

* Mux 블록의 역할 이해
* 여러 개의 신호를 하나의 신호로 묶기
* Scope에서 여러 신호를 동시에 모니터링하기

---

## 프로젝트 개요

자동차 ECU는 하나의 센서만 사용하는 것이 아니라 차량 속도, 엔진 RPM, 냉각수 온도 등 다양한 센서 데이터를 동시에 처리한다.

이번 실습에서는 Simulink의 Mux 블록을 이용하여 여러 신호를 하나의 벡터 신호로 결합하고 Scope에서 동시에 확인하는 방법을 학습하였다.

---

## 사용한 블록

* Constant
* Ramp
* Mux
* Scope

---

## 모델 구성

Ramp → Mux

Constant → Mux

Mux → Scope

---

## 학습 내용

* Mux(Number of Inputs) 설정
* 여러 입력 신호 연결
* Scope에서 다중 그래프 확인
* 벡터 신호의 개념 이해

---

## 실제 자동차 제어에서 활용

차량 ECU는 CAN 통신을 통해 여러 센서 데이터를 동시에 수신한다.

Mux는 이러한 여러 데이터를 하나의 신호 묶음으로 표현할 때 사용하는 기본 개념과 유사하다.

예를 들어 차량 속도, 엔진 RPM, 냉각수 온도를 동시에 모니터링하여 차량 상태를 분석할 수 있다.

---

## 느낀 점

자동차 제어에서는 하나의 값만 보는 것이 아니라 여러 센서 정보를 동시에 분석해야 한다는 점을 이해하였다.
