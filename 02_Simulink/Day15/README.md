# Day15 - Dashboard 블록과 운전자 입력

## 학습 목표

* Dashboard 블록 이해
* Knob 사용법
* Gain 블록과 연결
* Display 출력 확인

---

## 프로젝트 개요

자동차 ECU는 운전자의 입력을 받아 차량을 제어한다. 이번 실습에서는 Dashboard의 Knob를 이용하여 운전자의 가속페달 입력을 가상으로 생성하고, Gain 블록을 통해 출력값을 계산하였다.

---

## 실습 내용

* Dashboard > Knob 추가
* Gain 블록 연결
* Display 출력 확인
* Simulation 중 실시간 입력 변경

---

## 실제 자동차 제어에서 활용

* Accelerator Pedal Position(APPS)
* 운전자 스로틀 입력
* 속도 명령 생성
* ECU 입력 테스트
* HIL(Hardware In the Loop) 시뮬레이션

---

## 오늘 배운 내용

* Dashboard
* Knob
* Gain
* Display
* 실시간 입력 제어

---

## 느낀 점

Dashboard 블록을 사용하면 Constant 값을 직접 수정하지 않고도 운전자의 입력을 실시간으로 시뮬레이션할 수 있었다. 실제 차량의 가속페달 입력을 테스트하는 방식과 유사한 구조를 경험하였다.
