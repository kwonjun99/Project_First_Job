# Day16 - Dashboard Lamp와 차량 경고 시스템

## 학습 목표

* Lamp 블록 사용
* Dashboard 출력 이해
* Relational Operator와 연동
* 차량 경고 시스템 구현

---

## 프로젝트 개요

자동차 계기판은 차량 상태를 운전자에게 시각적으로 알려준다. 이번 실습에서는 Dashboard Lamp를 이용하여 제한 속도를 초과했을 때 경고등이 켜지는 간단한 차량 안전 시스템을 구현하였다.

---

## 실습 내용

* Dashboard Lamp 추가
* 속도 비교(Relational Operator)
* 조건에 따른 Lamp ON/OFF
* Dashboard와 논리 블록 연결

---

## 실제 자동차 제어에서 활용

* 과속 경고등
* 엔진 체크등(MIL)
* ABS 경고등
* ESC 경고등
* 배터리 경고등
* 엔진 과열 경고등

Dashboard Lamp는 실제 계기판의 표시등과 동일한 개념으로 ECU의 상태를 운전자에게 전달한다.

---

## 오늘 배운 내용

* Dashboard Lamp
* 조건 비교
* Boolean 신호
* 경고등 제어
* 차량 상태 표시

---

## 느낀 점

Dashboard 블록을 활용하면 실제 차량 계기판과 유사한 인터페이스를 구현할 수 있었다. 단순한 신호 계산을 넘어 운전자와 상호작용하는 시스템을 설계하는 방법을 익혔다.
