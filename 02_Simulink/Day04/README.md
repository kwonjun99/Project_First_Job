# Day04 - Step 입력과 차량 제어 이벤트

## 학습 목표

* Step 블록을 이용한 순간적인 입력 생성
* Gain 및 Sum 블록과 함께 신호 처리
* Scope를 이용한 Step 응답 확인

## 프로젝트 개요

차량에서는 운전자가 가속 페달이나 브레이크를 갑자기 조작하는 경우가 많다. 이러한 입력은 Step 신호로 표현할 수 있다. 이번 실습에서는 Step 입력을 이용해 ECU가 입력을 처리하는 과정을 모델링하였다.

## 사용한 블록

* Step : 특정 시점에서 값이 변경되는 입력
* Gain : 입력 신호 증폭
* Sum : 신호 연산
* Display : 결과 확인
* Scope : 입력 변화 시각화

## 모델 구성

Step → Gain → Sum(+Constant) → Display

## 실제 자동차 제어에서 활용

크루즈 컨트롤 ON/OFF, 브레이크 스위치, 가속 페달 입력, 기어 변경 등 대부분의 이벤트성 입력은 Step 신호와 유사하게 모델링하여 제어기를 검증한다.

## 학습 내용

* Step Time
* Initial Value
* Final Value
* Gain 및 Sum과의 연동

## 느낀 점

Step 입력을 통해 차량 제어 시스템이 특정 시점의 이벤트를 어떻게 처리하는지 이해할 수 있었으며, 이후 PID 제어와 ACC 프로젝트의 기초가 되는 입력 방식임을 확인하였다.
