## 실습 내용

현대자동차 ECU는

ACC

LKA

ESC

EPS

Motor

등 대부분의 제어기에 PID 제어를 사용한다.

P Gain은 제어 반응 속도를 결정하는 가장 중요한 파라미터이다.
