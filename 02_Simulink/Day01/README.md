## 학습 목표

* MATLAB과 Simulink 개발 환경 이해
* Simulink 모델 생성 및 저장
* Constant, Display, Scope 블록 사용법 학습
* 자동차 제어 시스템에서 신호 흐름 이해

---

## 프로젝트 개요

Simulink는 자동차 제어 소프트웨어를 그래픽 방식으로 설계하는 모델 기반 개발(Model-Based Design) 도구이다.

현대자동차, 현대모비스 등에서는 차량 제어 알고리즘을 Simulink로 설계한 후 ECU에 탑재할 C 코드로 변환한다.

이번 실습에서는 Simulink 개발 환경을 익히고 가장 기본적인 신호 흐름을 구현하였다.

---

## 사용한 블록

### Constant

고정된 값을 출력하는 블록이다.

실제 자동차에서는 센서 입력을 테스트하거나 일정한 기준값을 입력할 때 사용된다.

---

### Display

입력된 값을 숫자로 출력하는 블록이다.

차량 계기판이나 디버깅 과정에서 현재 데이터를 확인하는 역할을 한다.

---

### Scope

시간에 따른 신호 변화를 그래프로 출력한다.

실제 차량 개발에서는 센서 데이터와 제어기의 출력 변화를 분석할 때 가장 많이 사용하는 블록이다.

---

## 모델 구성

Constant → Display

Constant → Scope

---

## 실행 결과

* Constant 값 150 출력 확인
* Scope에서 일정한 값이 수평선으로 출력되는 것을 확인

## 실제 자동차 제어에서 활용

ECU는 센서에서 입력된 신호를 받아 처리한 후 계기판 또는 다른 제어기로 전달한다.

이번 실습은 이러한 데이터 흐름을 가장 단순한 형태로 구현한 것이다.

## 느낀 점

Simulink는 코드를 직접 작성하는 것이 아니라 블록을 연결하여 차량 제어 로직을 설계하는 도구라는 점을 이해하였다.
