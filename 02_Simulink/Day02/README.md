# Day02 - Gain과 Sum을 이용한 신호 처리

## 학습 목표

* Gain 블록을 이용한 신호 증폭
* Sum 블록을 이용한 신호 연산
* 여러 블록을 연결하여 간단한 제어 흐름 구성

---

## 프로젝트 개요

자동차 ECU는 센서 데이터를 그대로 사용하는 것이 아니라 다양한 계산을 수행한다.

이번 실습에서는 Gain과 Sum 블록을 이용하여 신호를 계산하는 과정을 학습하였다.

---

## 사용한 블록

### Gain

입력 신호에 일정한 값을 곱한다.

예를 들어 차량 속도를 단위 변환하거나 제어기의 이득(Gain)을 적용할 때 사용한다.

---

### Sum

여러 신호를 더하거나 뺄 수 있는 블록이다.

실제 PID 제어에서는 목표 속도와 현재 속도의 차이를 계산할 때 사용된다.

---

## 모델 구성

### 모델 1

Constant → Gain → Display

예시

* Constant = 100
* Gain = 2
* 출력 = 200

---

### 모델 2

Constant + Constant → Sum → Display

예시

* 150 + 50 = 200

---

### 과제

Constant(60)

↓

Gain(2)

↓

Sum(+30)

↓

Display

최종 출력

150

---

## 실제 자동차 제어에서 활용

차량 ECU는 센서 데이터를 증폭하거나 보정한 후 여러 데이터를 계산하여 최종 제어 명령을 생성한다.

Gain은 신호 보정, Sum은 속도 오차 계산, 토크 계산 등 다양한 제어 알고리즘에서 사용된다.
