# Day24 - Feedback Control

## 목표

Feedback의 중요성을 이해하고 PID Gain 변화에 따른 차량 응답을 비교하였다.

---

## 실습 내용

- 목표 속도 변경
- P Gain 변경
- Scope 비교

---

## 자동차에서의 사용

자동차는 현재 속도를 지속적으로 측정하여 목표 속도와 비교한다.

이 정보를 기반으로 스로틀을 제어하여 원하는 속도를 유지한다.

---

## 오늘 배운 내용

- Feedback
- Gain Tuning
- Vehicle Response
- Closed Loop

---

## 실제 자동차에서 어디에 쓰이는가?

ACC, 크루즈 컨트롤, 전기차 모터 제어 등에서는 현재 속도를 계속 측정하여 오차를 줄이는 피드백 제어가 사용된다.

---

## 느낀 점

PID의 성능은 Gain 값에 따라 크게 달라지며, 실제 자동차에서도 반복적인 튜닝을 통해 안정적인 주행 성능을 만든다는 것을 이해하였다.
