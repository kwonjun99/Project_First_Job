## 실제 자동차에서 어디에 쓰이는가?

차량은 현재 속도를 ECU로 계속 보내고, ECU는 목표 속도와 비교하여 스로틀을 조절한다. 이 피드백 구조가 ACC와 크루즈 컨트롤의 핵심이다.

## 느낀 점

오늘부터는 단순 블록 연결이 아니라 실제 차량 제어 시스템과 동일한 구조를 구현하기 시작하였다.

Quiz 1. Transfer Function(전달함수)은 자동차에서 무엇을 의미하는가?수학적 의미: * 전달함수(Transfer Function)는 "입력(Input) 대비 출력(Output)의 관계를 표현한 수학적 모델"입니다.자동차 시스템에서의 비유 및 의미:자동차 제어에서 전달함수는 '자동차 본체(피제어 대상, Plant)' 그 자체의 물리 특성을 나타냅니다.입력($u$): 가속 페달을 누르는 정도 (또는 스로틀 밸브 개폐율, 모터 인가 전압 등)출력($y$): 자동차의 실제 속도 (또는 이동 거리)전달함수의 역할: "가속 페달을 $X$만큼 밟았을 때, 자동차의 무게, 공기 저항, 바퀴 마찰력 등을 고려하면 속도가 어떻게 변화하는가?"를 나타내는 방정식입니다. 즉, 가속 페달 입력이 들어왔을 때 차량이 어떻게 반응하는지 결정하는 물리적 차량 동작 특성의 지도/모델입니다.
Quiz 2. 왜 출력을 다시 Sum(합산기)으로 보내는가?핵심 이유: 피드백(Feedback)을 통한 '오차(Error)' 계산상세 설명:목표치(Reference)와 현재 상태(Output) 비교:자율주행이나 크루즈 컨트롤 시스템에서 운전자가 설정한 목표 속도(예: $100\text{ km/h}$)와 센서로 측정한 실제 현재 속도(예: $90\text{ km/h}$)의 차이를 구해야 합니다.Sum 기호의 역할:Sum 블록에 목표 속도는 $(+)$로, 실제 출력 속도는 $(-)$로 전달됩니다.이를 통해 $\text{오차}(e) = \text{목표 속도} - \text{현재 속도}$를 실시간으로 계산합니다.PID 제어기의 작동:출력을 다시 보내서 만든 이 '오차 값'이 바로 PID 제어기 입력으로 전달됩니다.제어기는 오차가 $0$이 될 때까지 가속 페달을 더 밟거나(오차가 양수일 때), 페달을 떼는(오차가 음수일 때) 제어 명령을 연속적으로 조정하게 됩니다.요약: * 출력을 다시 Sum으로 보내지 않으면(Open-Loop), 경사로나 바람 등 외부 방해 요소(외란)가 생겼을 때 속도가 떨어져도 제어기가 알지 못합니다.출력을 되돌려보냄(Closed-Loop)으로써 현재 상태를 실시간으로 감지하고 오차를 줄여 목표에 정확히 도달하게 만듭니다.
