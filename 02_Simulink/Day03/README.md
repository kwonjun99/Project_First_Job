# Day03 - Ramp 블록과 시간에 따라 변하는 신호

## 학습 목표

* Ramp 블록을 이용하여 시간에 따라 증가하는 신호 생성
* Gain 블록으로 신호 증폭
* Scope를 이용한 신호 변화 관찰

## 프로젝트 개요

자동차의 속도와 RPM은 시간이 지나면서 계속 변한다. 이번 실습에서는 Ramp 블록을 사용하여 실제 차량이 점차 가속하는 상황을 모델링하였다.

## 사용한 블록

* Ramp : 시간에 따라 일정한 비율로 증가하는 신호 생성
* Gain : 입력 신호를 일정한 비율로 증폭
* Display : 현재 값 확인
* Scope : 시간에 따른 신호 변화 확인

## 모델 구성

Ramp → Gain → Scope

## 실제 자동차 제어에서 활용

차량이 출발하여 점차 속도를 높이는 상황, 목표 속도까지 가속하는 시뮬레이션 등에 사용된다.

## 학습 내용

* 시간 기반 신호
* Ramp 파라미터(Slope, Start Time)
* Scope를 이용한 신호 분석

## 느낀 점

Constant와 달리 Ramp는 시간에 따라 값이 변하는 신호를 만들 수 있어 실제 자동차의 가속 상황을 표현하기에 적합하다는 것을 이해하였다.
