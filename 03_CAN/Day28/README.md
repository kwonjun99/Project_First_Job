① CAN이 무엇인가?

CAN은 Controller Area Network의 약자로 자동차 ECU들이 서로 데이터를 빠르게 주고받기 위한 직렬 통신 프로토콜입니다.

② CAN의 장점은?
배선 감소
실시간 통신
높은 신뢰성
자동 오류 검출
자동 재전송
③ CAN ID가 하는 역할은?

메시지를 구분하는 식별자이며, 동시에 우선순위를 결정합니다.

④ Arbitration이란?

여러 ECU가 동시에 송신할 때 우선순위가 높은 CAN ID가 먼저 전송되는 과정입니다.

⑤ ACK Error란?

수신 ECU가 ACK를 보내지 않아 발생하는 오류이며, CAN Controller가 자동으로 재전송합니다.

⑥ DBC란?

CAN 데이터를 사람이 이해할 수 있도록 정의한 데이터베이스 파일입니다.

⑦ CAN FD란?

기존 CAN보다 최대 64Byte까지 데이터를 전송할 수 있고 더 높은 속도를 지원하는 확장 규격입니다.

⑧ UDS란?

ECU를 진단하기 위한 표준 진단 프로토콜입니다.

⑨ OBD-II란?

차량 진단을 위한 국제 표준 시스템으로, 진단기를 통해 ECU 정보를 확인할 수 있습니다.

⑩ CANoe란?

CAN 네트워크를 분석하고 테스트하는 대표적인 실무 프로그램입니다.
