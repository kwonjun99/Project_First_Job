# Day21 - Car Status Manager

## 학습 목표

* 구조체를 이용하여 차량의 상태를 하나의 데이터로 관리
* enum을 이용하여 기어 상태 표현
* 함수를 이용하여 차량 상태 출력

---

## 프로젝트 개요

이번 프로젝트에서는 자동차의 기본 상태를 하나의 구조체(`CarStatus`)로 관리하였다.

관리하는 데이터

* Speed
* RPM
* Engine Temperature
* Gear

---

## 핵심 코드

```c
struct CarStatus
{
    int speed;
    int rpm;
    float temperature;
    enum Gear gear;
};
```

차량의 여러 정보를 하나의 구조체로 묶어 관리하였다.

---

## enum 활용

```c
enum Gear
{
    P,
    R,
    N,
    D
};
```

기어 상태를 숫자가 아닌 의미 있는 이름으로 표현하였다.

---

## 함수

```c
printStatus()
```

함수를 이용하여 차량 상태를 출력하였다.

---

## 오늘 배운 내용

* 구조체 설계
* enum 활용
* switch문
* 함수를 이용한 데이터 출력

---

## 실제 자동차 제어에서 어디에 사용될까?

자동차 ECU는 차량의 속도, 엔진 RPM, 기어 위치, 엔진 온도와 같은 여러 센서 및 상태 정보를 하나의 데이터 구조로 관리한다. 이러한 방식은 차량 상태를 효율적으로 처리하고 다른 제어 모듈과 정보를 공유하는 데 사용된다.

---

## 느낀 점

구조체를 이용하면 서로 관련된 차량 데이터를 하나의 객체처럼 관리할 수 있어 코드가 훨씬 직관적이고 유지보수가 쉬워진다는 것을 이해하였다.
