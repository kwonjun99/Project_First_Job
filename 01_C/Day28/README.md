Vehicle Warning System
# Day28 - Vehicle Warning System

## 학습 목표

* 차량 상태를 분석하여 경고를 출력한다.
* 조건문을 이용한 차량 상태 판단 로직을 작성한다.
* 차량 안전 기능의 기본 원리를 이해한다.

---

## 프로젝트 개요

자동차는 현재 차량 상태를 지속적으로 확인하여 운전자에게 경고를 제공한다.

이번 프로젝트에서는 차량 속도와 엔진 RPM을 확인하여 과속과 고회전 상태를 판단하는 간단한 경고 시스템을 구현하였다.

---

## 핵심 코드

```c
if(car.speed > 120)
```

과속 여부를 판단한다.

```c
if(car.rpm > 5000)
```

엔진 과회전 여부를 판단한다.

필요한 조건에 따라 각각의 경고 메시지를 출력한다.

---

## 오늘 배운 내용

* 조건문을 이용한 상태 판단
* 차량 이상 상태 감지
* 경고 시스템 설계

---

## 실제 자동차 제어에서 어디에 사용될까?

실제 차량에서는 ECU가 센서 데이터를 지속적으로 분석하여 과속, 과열, 엔진 과회전, 배터리 이상 등 다양한 상황을 감지한다.

이러한 판단 결과는 계기판 경고등, 경고음, 출력 제한(Limp Mode) 등의 기능으로 이어진다.

이번 프로젝트는 차량 진단 로직의 가장 기초적인 형태를 구현한 것이다.

---

## 느낀 점

단순히 데이터를 출력하는 것이 아니라 차량 상태를 판단하여 필요한 경고를 제공하는 프로그램을 작성하면서 제어 소프트웨어의 역할을 조금 더 이해할 수 있었다.
