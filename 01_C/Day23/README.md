# Day23 - CAN Message Structure

## 학습 목표

* 구조체를 이용하여 CAN 메시지 데이터 구성
* 차량의 여러 정보를 하나의 메시지로 관리
* 함수를 이용하여 CAN 메시지 출력

---

## 프로젝트 개요

이번 프로젝트에서는 실제 CAN 통신에서 사용되는 데이터 구조를 C언어 구조체로 표현하였다.

CAN 통신에서는 ECU들이 하나의 메시지 안에 여러 데이터를 담아 서로 주고받는다.

이번 실습에서는 다음 데이터를 하나의 구조체로 관리하였다.

* CAN ID
* Vehicle Speed
* Engine RPM
* Engine Temperature

---

## 핵심 코드

```c
struct CANMessage
{
    int id;
    int speed;
    int rpm;
    float temperature;
};
```

각 센서 정보를 하나의 구조체에 저장하여 하나의 CAN 메시지처럼 관리하였다.

---

## 함수

```c
printMessage()
```

CAN 메시지 안에 저장된 모든 데이터를 출력한다.

## 실제 자동차 제어에서 어디에 사용될까?

실제 차량에서는 엔진 ECU, 변속기 ECU, ABS ECU 등이 CAN 네트워크를 통해 데이터를 주고받는다.

예를 들어 엔진 ECU는 차량 속도, 엔진 RPM, 냉각수 온도 등의 정보를 하나의 CAN 프레임으로 전송하며, 다른 ECU는 해당 정보를 받아 차량을 제어한다.

이번 프로젝트는 이러한 CAN 데이터 관리 방식을 C언어 구조체로 이해하기 위한 기초 단계이다.

---

## 느낀 점

자동차의 여러 센서 정보를 하나의 구조체에 저장하면 관리가 쉬워지고 실제 CAN 통신에서 사용하는 데이터 구조와 비슷한 형태를 만들 수 있다는 것을 이해하였다.
