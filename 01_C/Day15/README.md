+----------------------+
|       Stack          |
|----------------------|
| 지역 변수            |
| 함수                 |
+----------------------+
->자동으로 생성되고 자동으로 삭제된다.
+----------------------+
|       Heap           |
|----------------------|
| malloc()으로 생성    |
| free()로 해제        |
+----------------------+
->직접 생성하고 직접 삭제한다.

자동차에서 사용하는 이유
: 차량마다 센서 개수가 다를 수 있다. 
센서 4개 또는 12개 처럼 실행 중에 필요한 만큼 메모리 만들 수 있다.
(일반적인 자동차 ECU에서는 메모리 사용을 예측하기 위해 malloc을 제한하거나 사용하지 않는 경우도 많다

malloc()을 이해하는 핵심

먼저 이 코드를 보자.

int speed;

이렇게 하면 int 하나를 만든다.

speed

└─────┘

그럼

int speed[3]이면?

speed

┌─────┬─────┬─────┐
│1000 │2000 │3000 │
└─────┴─────┴─────┘

int 3개 공간을 만든 것이다.

그런데 malloc()도 똑같다.

malloc(sizeof(int))의 의미는

int 하나를 넣을 공간을 만들어 달라는 뜻이다.

Heap

┌─────┐
│     │
└─────┘

은

Heap

┌─────┬─────┬─────┐

int 3개를 저장할 수 있는 공간을 만드는 것이다.

12 Byte

# Stack

지역 변수는 Stack 메모리에 저장된다.

함수가 종료되면 자동으로 메모리가 해제된다.

---

# Heap

Heap 메모리는 malloc()으로 생성한다.

사용이 끝나면 반드시 free()를 호출하여 메모리를 해제해야 한다.

---

# malloc()

```c
int *p;

p = (int *)malloc(sizeof(int));
```

Heap에 int 하나를 생성한다.

---

# free()

```c
free(p);
```

생성한 메모리를 해제한다.

# 느낀 점

동적 메모리는 프로그램 실행 중 필요한 만큼 메모리를 생성할 수 있는 기능이다.

메모리 누수(Memory Leak)를 방지하기 위해 free()를 반드시 호출해야 한다.
