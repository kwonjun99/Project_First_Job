# Day24 - Vehicle Data Logger

## 학습 목표

* 구조체 배열 사용
* 여러 시점의 차량 데이터 저장
* 반복문을 이용한 데이터 출력

---

## 프로젝트 개요

자동차는 주행 중 차량의 상태를 지속적으로 기록한다.

이번 프로젝트에서는 차량의 속도와 엔진 RPM을 여러 개 저장하기 위해 구조체 배열을 사용하였다.

---

## 핵심 코드

```c
struct VehicleData
{
    int speed;
    int rpm;
};
```

구조체 하나는 차량 한 순간의 데이터를 의미한다.

```c
struct VehicleData log[4];
```

배열을 이용하여 여러 순간의 차량 데이터를 저장하였다.

---

## 함수

```c
printData()
```

구조체 하나의 데이터를 출력한다.

반복문을 이용하여 배열 전체를 출력하였다.

---

## 오늘 배운 내용

* 구조체 배열
* 반복문
* 데이터 기록(Log)

---

## 실제 자동차 제어에서 어디에 사용될까?

자동차 ECU는 차량 주행 중 속도, 엔진 RPM, 조향각, 브레이크 상태, 배터리 전압 등의 데이터를 일정 주기(예: 10ms, 100ms)마다 저장한다.

이러한 로그 데이터는 차량 진단, 고장 분석, 성능 평가, 자율주행 알고리즘 검증 등에 활용된다.

이번 프로젝트는 이러한 데이터 로깅(Data Logging)의 기본 원리를 구조체 배열을 통해 구현한 것이다.

---

## 느낀 점

배열을 사용하면 여러 시점의 차량 데이터를 한 번에 저장하고 출력할 수 있어 실제 차량의 데이터 기록 방식과 비슷한 구조를 만들 수 있다는 것을 이해하였다.
