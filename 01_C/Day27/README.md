# Day27 - Vehicle Controller

## 학습 목표

* 차량의 여러 상태(속도, RPM, 기어)를 하나의 구조체로 관리한다.
* 포인터를 이용하여 차량 상태를 변경하는 함수를 작성한다.
* 여러 개의 제어 함수를 하나의 프로그램에서 사용하는 방법을 익힌다.

---

## 프로젝트 개요

이번 프로젝트에서는 차량 제어 시스템의 기본 구조를 구현하였다.

차량의 속도(Speed), 엔진 회전수(RPM), 기어(Gear)를 하나의 구조체에 저장하고, 각각의 값을 변경하는 함수를 작성하였다.

마지막으로 차량의 현재 상태를 출력하는 기능까지 구현하였다.

---

## 핵심 코드

```c
struct Vehicle
{
    int speed;
    int rpm;
    enum Gear gear;
};
```

하나의 구조체에 차량의 핵심 상태를 저장하였다.

---

### 차량 상태 변경 함수

```c
updateSpeed()

updateRPM()

updateGear()
```

각 함수는 포인터를 이용하여 실제 차량 정보를 직접 변경한다.

## 실제 자동차 제어에서 어디에 사용될까?

자동차 ECU는 속도, 엔진 RPM, 기어 위치와 같은 차량 상태를 하나의 데이터 구조로 관리한다.

가속 제어, 변속 제어, 주행 안정화 제어와 같은 기능은 모두 동일한 차량 상태 데이터를 참조하며 필요한 값을 변경한다.

이번 프로젝트는 이러한 ECU 내부의 데이터 관리 방식을 단순화하여 구현한 것이다.

---

## 느낀 점

여러 개의 기능을 하나의 프로그램으로 연결하면서 코드가 점점 실제 프로그램의 형태를 갖추기 시작했다. 구조체와 포인터를 함께 사용하면 차량 상태를 효율적으로 관리할 수 있다는 것을 이해하였다.
