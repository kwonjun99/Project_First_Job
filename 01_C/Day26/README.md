# Day26 - Driving Mode Management

## 학습 목표

* enum을 이용하여 차량의 주행 모드를 표현한다.
* switch문으로 각 주행 모드에 따른 정보를 출력한다.
* 의미 있는 상수를 사용하여 코드의 가독성을 높인다.

---

## 프로젝트 개요

최근 자동차는 다양한 주행 모드를 제공한다.

대표적인 예

* ECO
* NORMAL
* SPORT

이번 프로젝트에서는 enum을 이용하여 주행 모드를 관리하고 현재 차량의 상태를 출력하는 프로그램을 작성하였다.

---

## 핵심 코드

```c
enum DriveMode
{
    ECO,
    NORMAL,
    SPORT
};
```

주행 모드를 숫자가 아닌 의미 있는 이름으로 표현하였다.

```c
switch(car.mode)
```

현재 주행 모드에 따라 적절한 문자열을 출력하였다.

---

## 오늘 배운 내용

* enum
* switch
* 차량 상태 관리

---

## 실제 자동차 제어에서 어디에 사용될까?

현대자동차, 기아 등에서 제공하는 ECO, NORMAL, SPORT 모드는 차량 제어 소프트웨어가 운전자의 선택에 따라 가속 응답, 변속 시점, 스티어링 감도 등을 변경하여 구현한다. 실제 ECU 내부에서도 이러한 주행 모드는 enum과 유사한 상태 값으로 관리되는 경우가 많다.

이번 프로젝트는 이러한 주행 모드 관리 방식을 단순화하여 구현한 것이다.

---

## 느낀 점

enum을 사용하면 숫자 대신 의미 있는 이름을 사용할 수 있어 코드의 가독성이 좋아지고, 자동차 제어 프로그램처럼 상태를 관리하는 코드에서 특히 유용하다는 것을 이해하였다.
