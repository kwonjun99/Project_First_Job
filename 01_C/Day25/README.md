# Day25 - Vehicle Sensor Update

## 학습 목표

* 구조체를 이용하여 차량 센서 데이터를 관리한다.
* 포인터를 활용하여 원본 데이터를 직접 수정하는 방법을 학습한다.
* 하나의 함수에서 여러 센서 값을 동시에 업데이트하는 방법을 이해한다.

---

## 프로젝트 개요

자동차는 주행 중 수많은 센서 데이터를 실시간으로 측정한다.

이번 프로젝트에서는 차량의 주요 센서 정보를 하나의 구조체(`Sensor`)에 저장하고, 포인터를 이용하여 센서 값을 갱신하는 프로그램을 작성하였다.

관리한 센서 데이터

* Vehicle Speed
* Engine RPM
* Engine Temperature

---

## 핵심 코드

```c
struct Sensor
{
    int speed;
    int rpm;
    float temperature;
};
```

센서 데이터를 하나의 구조체로 관리하였다.

```c
void updateSensor(struct Sensor *car, int speed, int rpm, float temp)
```

포인터를 이용하여 원본 구조체의 값을 직접 수정하였다.

---

## 오늘 배운 내용

* 구조체 포인터
* Call by Address
* 여러 데이터를 한 번에 업데이트하는 함수 설계

---

## 실제 자동차 제어에서 어디에 사용될까?

자동차 ECU는 일정한 주기(예: 10ms 또는 100ms)마다 차량 속도, 엔진 RPM, 냉각수 온도 등의 센서 값을 읽어 내부 메모리에 저장한다. 이후 다른 제어 알고리즘은 이 최신 센서 데이터를 기반으로 연료 분사, 점화 시기, 변속 제어 등을 수행한다.

이번 프로젝트는 이러한 센서 데이터 갱신 과정을 단순화하여 구현한 것이다.

---

## 느낀 점

포인터를 이용하면 함수 안에서도 원본 구조체를 직접 수정할 수 있다는 것을 다시 확인하였다. 여러 센서 값을 하나의 함수에서 함께 관리하면 코드가 간결하고 유지보수가 쉬워진다는 점도 이해하였다.
