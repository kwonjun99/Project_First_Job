# Day17 - Structure Array Project

## 학습 목표

- 구조체 배열 사용
- 여러 개의 데이터를 효율적으로 관리
- 반복문과 구조체를 함께 사용

---

## 구조체 배열

```c
struct Car cars[3];
```

구조체를 배열로 선언하여 여러 차량의 정보를 저장할 수 있다.

---

## 저장 예시

- Car1 : Speed 80, RPM 2200
- Car2 : Speed 100, RPM 2800
- Car3 : Speed 120, RPM 3500

- 데이터 관리
