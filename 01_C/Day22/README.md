# Day22 - Pointer Based Vehicle Update

## 학습 목표

* 구조체 포인터 이해
* 함수를 이용한 차량 상태 변경
* 포인터를 통한 원본 데이터 수정

---

## 프로젝트 개요

차량의 속도와 RPM을 변경하는 함수를 작성하였다.

```c
updateSpeed()
updateRPM()
```

두 함수 모두 구조체 포인터를 사용하여 차량의 실제 데이터를 수정한다.

---

## 핵심 코드

```c
void updateSpeed(struct CarStatus *car, int speed)
{
    car->speed = speed;
}
```

`->` 연산자는 구조체 포인터가 가리키는 멤버에 접근할 때 사용한다.

다음 두 문장은 같은 의미이다.

```c
car->speed
```

```c
(*car).speed
```

---

## 오늘 배운 내용

* 구조체 포인터
* 주소 전달(Call by Address)
* 함수를 통한 데이터 수정

---

## 실제 자동차 제어에서 어디에 사용될까?

자동차 ECU에서는 하나의 차량 상태 데이터를 여러 제어 함수가 공유한다. 예를 들어 가속 제어, 변속 제어, 엔진 제어 함수는 모두 동일한 차량 상태 구조체를 수정해야 하므로 포인터를 사용하여 원본 데이터를 직접 변경하는 방식이 많이 사용된다.

---

## 느낀 점

포인터를 이용하면 함수 안에서도 원본 구조체를 직접 수정할 수 있다는 것을 이해하였다. 이는 자동차 제어 프로그램처럼 여러 기능이 하나의 차량 정보를 함께 사용하는 환경에서 매우 중요한 개념이다.
